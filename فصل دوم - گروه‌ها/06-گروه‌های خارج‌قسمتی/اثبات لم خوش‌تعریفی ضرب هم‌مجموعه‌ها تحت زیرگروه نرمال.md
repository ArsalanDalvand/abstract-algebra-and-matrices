# 🔬 اثبات لم خوش‌تعریفی ضرب هم‌مجموعه‌ها تحت زیرگروه نرمال

> [!abstract] ایده محوری برهان (Proof Core Strategy)
> اثبات بر پایه برابری $Ny = yN$ و اتحاد مجموعه‌ای $N^2 = N$ به صورت $(xN)(yN) = x(Ny)N = xyN^2 = xyN$ (ص ۲۷).
