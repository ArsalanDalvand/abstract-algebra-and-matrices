# 🔬 اثبات نتیجه قضیه لاگرانژ درباره توان همانی مرتبه گروه

> [!abstract] ایده محوری برهان (Proof Core Strategy)
> اثبات با تشکیل زیرگروه دوری $X = \langle x \rangle$ با مرتبه $m = |x|$ و استفاده از $|X| \mid |G| \implies n = mr$ و در نتیجه $x^n = (x^m)^r = e^r = e$ (ص ۲۰).
