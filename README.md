# 🌐 مبانی جبر و ماتریس‌ها (Abstract Algebra and Matrices)
### پایگاه دانش اتمیک زتل‌کاستن و گراف دانش ریاضیات (Obsidian Knowledge Base)
#### منطبق بر استاندارد هستی‌شناسی ریاضیات UMKO v1.1

این مخزن شامل **پایگاه دانش اتمیک (Atomic Knowledge Base)**، ساختارمند، خودبسنده و متصل بر پایه درس دانشگاهی **«مبانی جبر و ماتریس‌ها»** (تدریس **دکتر علیرضا علائیان**، دانشکده ریاضی دانشگاه علم و صنعت ایران) است که با متدولوژی زتل‌کاستن و استانداردهای نوین مهندسی دانش بازطراحی شده است.

---

## 🌟 ویژگی‌های برجسته این پایگاه دانش

1. **متدولوژی اتمیک زتل‌کاستن (Zettelkasten):**
   * هر مفهوم، قضیه، برهان، مثال، دام آموزشی و تمرین در یک یادداشت مستقل و تک‌مفهومی (`.md`) تدوین شده است.
   * ارتباطات مفهومی با ویکی‌لینک‌های متقابل (`[[...]]`) و روابط استنتاجی تخت (`rel_*`) پیوند خورده‌اند.
2. **تفکیک قطعی صورت گزاره از برهان صوری (Assertion vs. Proof):**
   * برخلاف جزوات سنتی، صورت قضایا به عنوان گزاره‌های مستقل با شهود و تحلیل ضرورت شروط ثبت شده‌اند و براهین صوری آن‌ها در یادداشت‌های مجزای `proof` با پیوند استنتاجی `rel_proves` مستقر گردیده‌اند.
3. **عایق‌بندی ضد-لو-رفتن پاسخ‌ها و آموزش سقراطی (Anti-Spoiler Shield):**
   * تمامی مسائل و تمرین‌های پایان فصل مجهز به **نردبان ۵ مرحله‌ای هدایت هوشمند جورج پولیا (سطوح ۰ تا ۴)** در کادرهای تاشو هستند.
   * راه‌حل‌های تشریحی در یادداشت‌های مستقل `solution` قرار دارند تا از نشت ناخواسته پاسخ به دانشجو یا هوش مصنوعی جلوگیری شود.
4. **انضباط صلب KaTeX و تایپوگرافی دوزبانه:**
   * تمامی فرمول‌های ریاضی با استانداردهای بدون خطای KaTeX، محیط‌های `pmatrix`، نمادهای استاندارد مجموعه‌ها و عملگرها نگارش شده‌اند.
   * رعایت کامل نیم‌فاصله‌های فارسی (ZWNJ) و مصون‌سازی جهت متن دوزبانه (Bidi Protection).
5. **نقشه‌های راه یادگیری چندگانه (Multi-Track Learning Roadmaps):**
   * نقشه مسیر آکادمیک و اثبات‌های صوری (Academic Proof Track).
   * نقشه کارگاه حل مسئله و آمادگی آزمون (Problem Solving Track).
   * نقشه گراف وابستگی مفاهیم و دیاگرام توپولوژیک (Concept Dependency Graph).
6. **سلامت ۱۰۰٪ گراف استنتاجی (Strict DAG):**
   * فاقد حتی یک پیوند شکسته (Zero Broken Links).
   * تضمین عدم وجود استدلال دوری در زنجیره اثبات‌ها و پیش‌نیازها به کمک الگوریتم‌های گراف.

## 🚀 راهنمای استفاده در ابسیدین (Obsidian)

1. این مخزن را درون والت (Vault) ابسیدین خود کلون کنید:
   ```bash
   git clone https://github.com/ArsalanDalvand/abstract-algebra-and-matrices.git
   ```
2. والت را با نرم‌افزار **Obsidian** باز کنید.
3. مطالعه را از فایل اصلی **`00-MOC نقشه راه کلان درس مبانی جبر و ماتریس‌ها.md`** یا درسنامه **`فصل اول - نیم‌گروه‌ها/00-درسنامه و نقشه راه فصل اول - نیم‌گروه‌ها.md`** آغاز نمایید.
4. برای تجربه بهینه نمودارها، اطمینان حاصل کنید که رندر بومی **Mermaid** در ابسیدین فعال است.
